# Embedded Systems Laboratory

**Status: 🟢 Active - Work in Progress**

A collection of hands-on embedded systems projects developed during my undergraduate studies in Informatics and Telecommunications at the University of the Peloponnese.

The repository focuses on practical applications of embedded programming, microcontrollers, and electronic circuits.

## Technologies
- C/C++ (Arduino)
- Arduino Uno
- Wokwi Simulator
- Visual Studio Code
